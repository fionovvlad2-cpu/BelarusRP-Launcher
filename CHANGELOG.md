## [1.0.0] - 2026-10-11

### Добавлено
- Поиск установленной GTA V (реестр и стандартные папки Steam / Rockstar / Epic) и клиента RAGE MP.
- Выбор сервера из списка, статус онлайн/оффлайн и время соединения.
- Вход и регистрация через API (HTTPS); токен хранится зашифрованным (Windows DPAPI).
- Запуск и подключение к серверу через RAGE MP (`rage://v/connect`).
- Проверка целостности клиента по манифесту SHA-256 (опционально).
- Автообновление лаунчера через GitHub Releases с проверкой контрольной суммы.
- Интерфейс на русском и английском, анимация запуска, адаптивный размер окна.
- Журнал ошибок, отправка отчётов (опционально), локальная статистика запусков.
- Кнопки VK и Discord.
