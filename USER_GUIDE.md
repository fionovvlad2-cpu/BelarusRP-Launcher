# Руководство пользователя — BELARUS RP Launcher

## Первый запуск
1. Скачайте `BelarusRP.exe` на сайте проекта и запустите. Если Windows показывает SmartScreen — «Подробнее» → «Выполнить в любом случае» (файл пока не имеет платной цифровой подписи; контрольную сумму можно сверить с `BelarusRP.exe.sha256` из релиза).
2. Лаунчер сам найдёт GTA V (Steam, Rockstar, Epic) и RAGE MP. Если не нашёл — установите их и перезапустите лаунчер. Лицензию GTA лаунчер подтвердить не может, он проверяет только наличие игры.

## Игра
- Выберите сервер слева (рядом показан статус и пинг).
- Нажмите **ИГРАТЬ** — запустится RAGE MP и подключение к серверу.
- **Проверить файлы** сверяет клиент с эталонным списком (если проект его настроил).

## Аккаунт
Вход и регистрация доступны, когда проект подключил сервер аккаунтов. Пароль не сохраняется; токен сессии хранится в зашифрованном виде (Windows DPAPI), расшифровать его может только ваша учётная запись Windows.

## Верхняя панель
- ☀/☾ — светлая и тёмная тема.
- EN/RU — язык интерфейса.

## Нижняя панель
- **VK / Discord** — соцсети проекта.
- **Журнал** — папка с логами (`%AppData%\BelarusRP`).
- **Отчёт об ошибке** — отправка версии, ОС и последних строк журнала разработчикам (после вашего подтверждения).
- **Обратная связь** — страница обратной связи проекта.
- **Профиль** — игровое время, история подключений, сохранённые логины (двойной щелчок подставляет логин).

## Обновления
Если вышла новая версия, сверху появится баннер «Обновить». Лаунчер скачает файл, проверит контрольную сумму и перезапустится.

## Частые проблемы
| Проблема | Что делать |
|---|---|
| GTA V не найдена | Один раз запустите её из Steam/Rockstar/Epic, перезапустите лаунчер |
| RAGE MP не найден | Установите с rage.mp, при запросе укажите `ragemp_v.exe` |
| «Закройте посторонние программы» | Закройте программу из списка в сообщении |
| Не обновляется | Переместите лаунчер в папку, где есть право записи (например, на рабочий стол) |
